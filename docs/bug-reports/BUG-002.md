# BUG-002: ปุ่ม Remove ในตะกร้าไม่ทำงาน ไม่มี error แจ้ง (error_user)

**Severity:** High | **Priority:** Medium
**Found in:** TC-013 | **Reported by:** Krittapas | **Date:** 16 ก.ย. 2569

## Environment
- URL: https://www.saucedemo.com
- Browser: Chrome (เวอร์ชันล่าสุด)
- Account: error_user / secret_sauce

## Precondition
1. Login ด้วย error_user สำเร็จ
2. มีสินค้าอยู่ในตะกร้าแล้ว 1 ชิ้น (Sauce Labs Backpack)
3. อยู่ที่หน้า Cart

## Steps to Reproduce
1. เปิด saucedemo.com
2. Login ด้วย username: error_user, password: secret_sauce
3. เพิ่มสินค้า "Sauce Labs Backpack" ลงตะกร้า
4. เข้าหน้า Cart
5. กดปุ่ม "Remove" ที่สินค้านี้

## Expected Result
สินค้าต้องถูกลบออกจากรายการในหน้า Cart และ badge บนไอคอนตะกร้าต้องหายไป

## Actual Result
กดปุ่ม Remove แล้วไม่มีอะไรเกิดขึ้น สินค้ายังคงอยู่ในตะกร้าเหมือนเดิม 
badge ยังแสดงเลขเท่าเดิม ไม่มี error message หรือสัญญาณใดๆ แจ้งผู้ใช้ว่า
เกิดปัญหา

## Reproduction Rate
Reproduce ได้ 100% ทุกครั้งที่ login ด้วย error_user แล้วลอง Remove สินค้า

## Impact
ผู้ใช้บัญชีนี้ไม่สามารถแก้ไขตะกร้าสินค้าได้เลย ติดอยู่กับสินค้าที่ไม่ต้องการ
โดยไม่มีวิธีแก้ไขภายใน flow ปกติ ต้อง logout หรือ refresh หน้าเพื่อเริ่มใหม่ 
ซึ่งอาจทำให้ข้อมูลอื่นในตะกร้าหายไปด้วย ถือเป็นปัญหาที่กระทบ core functionality
โดยตรงและไม่มีการแจ้งเตือนผู้ใช้เลย ทำให้ผู้ใช้สับสนว่าเกิดอะไรขึ้น

## Suspected Cause
คาดว่า event handler ของปุ่ม Remove ถูก override หรือ block ไว้เฉพาะ
สำหรับ account ประเภทนี้ (เป็น demo account ที่ตั้งใจฝังบั๊กไว้เพื่อการฝึก
ทดสอบ) อาจเกี่ยวข้องกับการจัดการ state ของตะกร้าที่ผูกกับ user role
