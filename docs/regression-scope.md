# Regression Test Scope — After Fixing BUG-002

## สถานการณ์

## Impact Analysis

| หลัก (RCRCRC) | พื้นที่ที่เสี่ยง | เหตุผล |
|---|---|---|
| Repaired | TC-013 | จุดที่เพิ่งแก้ ต้องยืนยันก่อนว่าแก้จริง |
| Core | TC-006, TC-012 | ระบบ Cart คือหัวใจของ flow การซื้อ ต้องมั่นใจว่าแก้แล้วไม่กระทบเคสที่เคย Pass |

| Chronic/Risky | TC-016, TC-017, TC-018, TC-019 | Checkout อ่านข้อมูลจากตะกร้าเดียวกัน หากแก้ Cart ผิดจุดอาจกระทบ Checkout ทั้ง flow |

## เคสที่ไม่รวมในขอบเขต (พร้อมเหตุผล)
- TC-001 ถึง TC-005 (Authentication) — ไม่เกี่ยวข้องกับโค้ดที่แก้เลย
- TC-008 ถึง TC-011 (Sort) — คนละส่วนของระบบ ไม่ได้ใช้ component ร่วมกับ Cart
- TC-020 ถึง TC-022 (Logout, URL redirect, Product listing) — ไม่เกี่ยวข้องกับ Cart logic

## สรุปขอบเขต Regression
