# Test Scenarios — SauceDemo

## Authentication
1. ผู้ใช้ปกติ login สำเร็จด้วยข้อมูลที่ถูกต้อง
2. ผู้ใช้ที่ถูกระงับบัญชี (locked_out_user) ไม่สามารถ login ได้
3. Login ด้วย username หรือ password ผิด ต้องแสดง error ที่เข้าใจได้
4. Login โดยเว้นช่องใดช่องหนึ่งว่าง

## Product Listing & Sorting
5. รายการสินค้าแสดงครบถ้วนหลัง login
6. เรียงสินค้าตามราคา (ต่ำ→สูง, สูง→ต่ำ) ได้ถูกต้อง
7. เรียงสินค้าตามชื่อ (A-Z, Z-A) ได้ถูกต้อง
8. รูปสินค้าแสดงถูกต้องตรงกับชื่อสินค้า (ทดสอบด้วย problem_user)

## Cart
9. เพิ่มสินค้าลงตะกร้าแล้วตัวเลขบน cart icon อัปเดตถูกต้อง
10. ลบสินค้าออกจากตะกร้าได้ (ทดสอบด้วย error_user ด้วย)
11. เพิ่มสินค้าหลายชิ้นแล้ว badge แสดงจำนวนถูกต้อง
12. ตะกร้าว่างแสดงสถานะที่เหมาะสม

## Checkout
13. กรอกข้อมูล checkout ครบถ้วนแล้วดำเนินการต่อได้
14. กรอกข้อมูล checkout ไม่ครบ ต้องแสดง error
15. ยกเลิกกลางทาง checkout แล้วกลับมาที่ cart ได้ถูกต้อง
16. Checkout สำเร็จแสดงหน้ายืนยันและตะกร้าถูกล้าง

## Session/Navigation
17. Logout แล้วกลับมาหน้า login ถูกต้อง ไม่เห็นข้อมูลเก่า
18. เข้าหน้า inventory โดยไม่ login (พิมพ์ URL ตรง) ต้องถูก redirect
